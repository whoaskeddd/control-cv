# Система управления видеокамерами

Абрамов Артём
Система управления видеокамерами: React + TS + FastAPI + PostgreSQL. 

## Запуск

```bash
docker compose up -d --build
```

- Приложение: http://localhost:3000
- API: http://localhost:8000
- Swagger: http://localhost:8000/docs

Compose запускает PostgreSQL, FastAPI и production-сборку React через встроенный preview-сервер Vite. База сохраняется в Docker volume `postgres_data`; SQL-инициализация выполняется при первом запуске пустого volume. Фронтенд обращается к `/api`, а Vite проксирует запросы в FastAPI. Перезагрузка вложенных страниц поддерживается.

## Фронтенд

Стек: React, TypeScript, Vite, Tailwind CSS 4, Framer Motion, React Router, Lucide, TanStack Query, React Hook Form и Zod.

| Страница | Адрес |
| --- | --- |
| Список, поиск, фильтры, сортировка | `/sources` |
| Добавление источника | `/sources/new` |
| Карточка источника | `/sources/:id` |
| Редактирование | `/sources/:id/edit` |

Фильтры, поиск, сортировка и страница списка сохраняются в URL. Поиск выполняется через API с задержкой 300 мс, фильтры по статусу/локации и пагинация по 8 строк — на клиенте. Счётчики показывают реальные данные API. Предусмотрены skeleton, пустой список, отсутствие совпадений, ошибка с повторным запросом, уведомления, подтверждение удаления и блокировка повторной отправки формы.

Поля `name`, `url`, `location` обязательны, обрезаются пробелы по краям, максимальная длина — 255 символов. URL должен содержать хост и протокол RTSP/HTTP(S). При ошибке сохранения введённые значения остаются в форме. Даты отображаются в часовом поясе браузера. Статус «Включён» обозначает настройку источника, а не доступность потока.


## API

| Метод | Адрес | Назначение |
| --- | --- | --- |
| `GET` | `/health` | Проверка работоспособности |
| `POST` | `/sources` | Создать источник |
| `GET` | `/sources?search=конвейер` | Получить список и найти источники |
| `GET` | `/sources/{id}` | Получить один источник |
| `PATCH` | `/sources/{id}` | Изменить поля или `enabled` |
| `DELETE` | `/sources/{id}` | Удалить источник |

Пример тела для создания:

```json
{
  "name": "Конвейер №1",
  "url": "rtsp://192.168.1.21/stream",
  "location": "Цех 3",
  "enabled": true
}
```

Допустимые схемы URL: `rtsp`, `http`, `https`. Название, адрес и расположение не могут быть пустыми.
